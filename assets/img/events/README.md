# Imágenes de eventos

Acá viven las fotografías de los eventos de la Agenda.

- Formato: **WebP**, horizontales, ideal ~1600×900 px, ≤ 200 KB.
- Nombre sugerido: `assets/img/events/<id-del-evento>.webp` (ej. `lab-problema-001.webp`).
- La imagen es **opcional**. Si un evento no tiene imagen, el sitio usa la
  fotografía predeterminada de su categoría (`agenda.categoryDefaults` en
  `data/config.json`).
- Usar solo fotografía real del lugar (Directriz §71). No generar flyers con
  texto: la información ya está en HTML (§39).
